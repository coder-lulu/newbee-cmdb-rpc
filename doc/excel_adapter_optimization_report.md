## 配置示例

### 基础配置
```go
config := &input.ExcelConfig{
    MaxFileSize:    50 * 1024 * 1024, // 50MB
    MaxRows:        50000,            // 50,000行
    SkipEmptyRows:  true,
    HeaderRow:      1,                // 第1行为表头
    DataStartRow:   2,                // 第2行开始数据
    RequiredFields: []string{"hostname", "ip_address"},
}
```

### 高级配置
```go
config := &input.ExcelConfig{
    ColumnMapping: map[string]string{
        "主机名":    "hostname",
        "IP地址":   "ip_address",
        "CPU核数":  "cpu_cores", 
        "内存(GB)": "memory_gb",
        "状态":     "status",
    },
    SheetMapping: map[string]string{
        "Sheet1": "assets",
    },
    RequiredFields: []string{"hostname", "ip_address"},
}
```
